# Moto Mods Developer Documentation (archive)

A restored, readable copy of the Moto Mods developer documentation Motorola
published at `developer.motorola.com` from 2016 until the portal was retired.
Rebuilt from Wayback Machine captures and served with MkDocs Material.

**📖 Read it: <https://jksim.github.io/moto-mods-developer-docs/>**

Moto Mods were snap-on hardware modules for the Moto Z phone. The platform was
opened to developers with a Mods Development Kit, a firmware stack built on
NuttX and Greybus, and an Android SDK. The documentation covered the system
architecture, eleven firmware protocols, the Android APIs, the reference
hardware, and worked examples — and then went offline with the product.

## What's here

| Path | Contents |
| --- | --- |
| `docs/` | The rebuilt documentation, as Markdown |
| `archive/` | The original captured HTML, untouched, with an index of provenance |
| `tools/` | The conversion pipeline that turns one into the other |
| `mkdocs.yml` | Generated by `tools/gen_mkdocs.py` — edit the script, not the file |

Two generations of the site were captured and both are represented: the 2016
Squarespace portal, which held the complete documentation, and the 2017 Drupal
portal that replaced it with a slimmer set. Where the later portal genuinely
revised a page, its version is the one you read; where it only reflowed the
same text, the original wins and the duplicate is kept in `archive/`. Every
page records which capture it came from in its front matter.

See [About This Archive](docs/about.md) for what was recovered, what is
missing, and why.

## Building locally

```console
$ pip install -r requirements.txt
$ mkdocs serve
```

Then open <http://127.0.0.1:8000/moto-mods-developer-docs/> — note the path.
`site_url` points at the GitHub Pages subdirectory, and `mkdocs serve` mirrors
it, so the bare root redirects.

## Regenerating from the captures

The conversion is reproducible but needs the raw captures, which are too large
to version here (`old_website/`, several GB, mostly unrelated MOTODEV-era
pages). With them in place:

```console
$ python3 tools/discover.py build/inventory.json   # find every Moto Mods page
$ python3 tools/convert.py build/inventory.json    # HTML -> Markdown + asset list
$ python3 tools/fetch_assets.py                    # localise images, fill gaps from Wayback
$ python3 tools/make_archive.py build/inventory.json
$ python3 tools/gen_mkdocs.py                      # nav from tools/manifest.py
```

`tools/manifest.py` is the single place that decides which captured page
becomes which documentation page, and in what order they appear in the nav.
